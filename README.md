# 🎮 Number Guessing Game

A simple conole-based Number Guessing Game written in Java.

The computer randomly selects a number between 1 and 100, and the player has to guess it.

## ✨ Features

- Random number generation
- User input validation
- Higher/lower hints
- Attept counter
- Score feedback
- Play again option
- Beginner-friendly Java code

## 🛠️ Technologies Used

- Java
- Java Scanner
- Java Random
- Loops
- Conditional Statements
- Methods

## 🚀 How to Run

1. Clone this repository
   ```bash
   git clone https://github.com/your-username/number-guessing-game.git
   ```
2. Navigate into the project folder
   ```bash
   cd number-guessing-game
   ```
3. Compile the program
   ```bash
   javac src/Main.java
   ```
4. Run it
   ```bash
   java -cp src Main
   ```

## 🎯 How to Play

1. Run the program
2. The computer picks a secret number between 1 and 100
3. Enter your guess when prompted
4. The gme tells you if your guess is too high or too low
5. Keep guessing until you find the number
6. See how many attempts it took you
7. Choose to play again or exit
