🎮 Number Guessing Game

A simple console-based Number Guessing Game written in Java.

The computer randomly selects a number between 1 and 100, and the player has to guess it.

✨ Features
Random number generation
User input validation
Higher/lower hints
Attempt counter
Score feedback
Play again option
Beginner-friendly Java code
🛠️ Technologies Used
Java
Java Scanner
Java Random
Loops
Conditional Statements
Methods
